# TEEView-CN · 经食管超声（TEE）切面模拟

面向心外科 / 麻醉 / 心超医师的 **ASE/SCA 标准 TEE 切面** 互动教学工具（中文界面）。

## 功能（v1.0.3）

- 体表（皮肤/肋骨）淡出至内部解剖
- 预设引导：蓝色 3D 箭头 + 中文步骤（进退/屈伸/扭转/多平面）
- 切面形态滑条：解剖彩切 ↔ 超声灰阶（结构标注保持）
- 轻量剑突下 TTE：四腔 / IVC


- 3D 心脏示意模型（心腔、二尖瓣 A1–P3、主动脉瓣、LAA、IAS、LVOT）+ 食管内虚拟 TEE 探头
- 探头控制：深度（上段/中段/经胃）、前屈/后屈、左右转、多平面角 0–180°
- 实时「超声风格」切面（扇区遮罩 + 灰度/斑点）
- 约 20 个常用 ASE/SCA TEE 预设切面 + 中文要点与术中提示
- 二尖瓣节段高亮、病理示意（MR / AS / 室壁运动异常 / 心包积液）
- 测验：辨认切面 或 把探头调到目标切面
- 离线单文件 HTML + Android APK；手机自适应

## 使用

- Web（GitHub Pages）：见仓库 Pages
- 本地：打开 `index.html`（需 `vendor/three.min.js`）或 `teeview-single.html`
- Android：Release 中的 APK

## 声明

仅供教学参考，解剖与声像为**简化示意**，不能替代临床培训与真实检查。
